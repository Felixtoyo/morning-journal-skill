# Nine-grid journal format

Use the user's language and local journal date. Preserve all nine cells in this row-major order, even when content is empty. The fixed order is an interview/output contract; questions for already-known content are skipped.

# 大富晨间日记 — YYYY-MM-DD

| ① 今天的梦想/长期目标 | ② 开心的事、值得感恩的事 | ③ 今天优先完成的3件最重要的事 |
| --- | --- | --- |
|  |  |  |
| ④ 健康状态 | ⑤ 金钱相关 | ⑥ 人际 |
|  |  |  |
| ⑦ 学习与输入 | ⑧ 烦恼/卡点/改善 | ⑨ 今日一句自我鼓励 |
|  |  |  |

写晨间日记不是记录流水账，而是把潜意识的想法显化，对齐自己的目标。

## Rendering and content rules

- Replace only the empty content cells with supplied facts and reflections. Never fill headings or examples as if user-provided.
- In Markdown cells escape literal pipes and use line breaks supported by the host. If tables render poorly, use nine numbered sections in the same order.
- “无/没有”, skipped, and missing information leave content blank. Do not insert invented encouragement or pad priorities to three.
- In health, retain dates, units, source, and known measurement time; distinguish metrics from subjective feelings. Never convert missing data to zero, normal, or a guessed score.
- Retain the reported interval for sleep spanning midnight. Keep conflicting measurements with their sources or ask one necessary clarification.
- Keep historical excerpts outside the nine cells so they cannot be mistaken for today's answers.
- Only when actively requested, append a separate 昨日复盘 / Yesterday's review section outside the grid; use supplied yesterday facts only.
- Append the core principle after the grid (or after a requested review), translated faithfully when appropriate. It is a practice principle, not an authenticated quotation.
- A stopped session stays incomplete. Do not force a final grid unless the user requests the partial draft.
